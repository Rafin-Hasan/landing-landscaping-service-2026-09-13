# Greenridge Landscaping

A single-page landing site (React + Vite + Tailwind CSS) for **Landscaping Service**.

## Run locally

```bash
npm install
npm run dev
```

## Features

- **Custom Design** — A landscape plan built around how you use your yard.
- **Seasonal Maintenance** — Ongoing care so it stays looking its best.
- **Licensed & Insured** — Experienced crews you can trust on your property.
- Fully responsive layout from mobile to desktop
- Keyboard-accessible navigation, visible focus states and reduced-motion support
- Email signup with inline confirmation

## Build for production

```bash
npm run build
npm run preview
```

The optimized site is written to `dist/`.
